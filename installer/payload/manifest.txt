# proven on the console in run 5 (2026-11-22); no GPL or non-commercial parts are shipped.

# Not listed on purpose: GPU microcode (gpu\fw\cyan_skillfish2_*.bin: copied at install time from the Linux image's
# /usr/lib/firmware/amdgpu, see DESIGN 2.5), p5bd (crashes), test programs, dev tasks, the ssh key, dgVoodoo2,
# and the Wi-Fi driver p5net (its MT7921 core carries recorded join frames of the user's own networks; a scanning
# Wi-Fi driver configured inside Windows replaces it later). build_payload.py refuses any file holding those details.
