READ ME FIRST - Windows on your PS5

1. Restart one more time now (Start > Restart, then start the PS5 Linux loader again).
   Audio and the full GPU driver only work from that second start on: until then, sound
   shows a red cross and Display Settings says Microsoft Basic Display Adapter.

2. Windows Update is turned off on purpose.
   An update can replace the Windows kernel, and this console then stops booting Windows.
   Please leave it off.

3. Set a password for this account.
   It signs in by itself and has no password yet:
   Settings > Accounts > Sign-in options > Password.

4. Anti-cheat: don't play online games with anti-cheat
   (EasyAntiCheat, BattlEye, Vanguard) on this install.
   Modified graphics files can get accounts banned.
   The game kit leaves such games alone, but don't try to run them.

5. The only official source of this project is its repository:
   <project repository URL>
   Don't trust copies or "builds" from anywhere else.
