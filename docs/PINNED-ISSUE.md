# Read before posting

**Supported console:** the launch PS5. The PS5 Slim is untested (reports welcome). The PS5 Pro is not supported.

**Anti-cheat:** games with kernel anti-cheat (EasyAntiCheat, BattlEye, Vanguard and similar) will not work, and trying
can get your game accounts banned. The game kit skips them on purpose.

**PS5 games:** ps5win does not touch PS5 games and never will. Requests about running PS5 games, or copies of them,
will be closed.

**Bugs:** use the **Bug report** template and attach the logs it asks for. Remove personal data (serial numbers,
network names, MAC/IP addresses) first.

**Security problems:** report them privately (Security tab, "Report a vulnerability"), never in a public issue.

**Questions:** please use Discussions. Before asking, see the [FAQ](docs/FAQ.md) and
[Troubleshooting](README.md#troubleshooting).
